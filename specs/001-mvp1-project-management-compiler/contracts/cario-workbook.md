# CARIO Workbook Contract

The workbook is a human-assisted fill file. It is not a native CARIO import
contract because the source does not provide evidence of a supported import
format.

## File name

`<ProjectName>_CARIO_GANTT.xlsx`

The application export keeps the six CARIO sheets below and appends the
management Gantt sheet `07_GANTT`. An explicitly requested non-authoritative
preview uses `<ProjectName>_CARIO_GANTT_PREVIEW.xlsx`; preview data is never
silently substituted into the official export.

The project name is sanitized for a file name only. The workbook content retains
the source project identity.

## XLSX preview import boundary

The application accepts an XLSX only as a read-only preview when the workbook
was freshly generated by this compiler and contains the seven-sheet CARIO plus
Gantt contract. The `05_PROJECT_INFO` sheet MUST contain exactly one instance of
each reserved marker row below:

```text
PMC_EXPORT_KIND                  CARIO_GANTT
PMC_EXPORT_CONTRACT_VERSION     1.0
PMC_PROJECT_ID                  <canonical project ID>
PMC_PROJECT_NAME                <canonical project name>
```

The preview importer is not an arbitrary Excel, CARIO, CSV, or legacy workbook
reader. A missing, duplicated, conflicting, unsupported, malformed, oversized,
or externally-linked package is rejected with a structured validation error.
The importer preserves the exported values and row order in a temporary
preview model only. It MUST NOT create or replace a `CanonicalProject`, source
execution evidence, analysis result, alert, proposal, or official export
snapshot. Preview state is cleared by a new official manifest import and is not
persisted or rehydrated after restart.

become separate rows. The source codes are exactly `A`, `R+`, `R`, `C`, `I`, and

### 07_GANTT

The Gantt sheet is a read-only presentation snapshot backed by the shared WBS
and Gantt projections. It has the following frozen identity columns before its
daily timeline:

```text
Level
Type
ID
Name
Lane
Status
Owner / Role
Plan Start
Plan Finish
Actual Start
Actual Finish

Source Reference
```

The timeline has one calendar-day column per day in the relevant project
window. PLAN bars use the immutable baseline, ACTUAL bars use recorded source
execution evidence, ALERT rows are derived conditions, and MILESTONE rows use a
zero-duration marker. Missing effort evidence is shown as `Not recorded`; the
export never infers a percentage from a bar width or from an absent record.

## Required export behavior

- `A`, `R+`, `R`, `C`, `I`, and `O` meanings come from source configuration;
- person, department, team, and priority fields remain blank without explicit
  configuration;
- unresolved mappings create warning rows, including explicit blank
  priority/department/team categories when those task mappings are absent;
- `Ngày bắt đầu dự kiến` and `Deadline` always use baseline planned dates;
  manual actual dates, alerts, and variance never replace or rename those
  planning fields;
- the six CARIO sheets remain plan-focused even when execution evidence exists;
  the separate `07_GANTT` sheet may show clearly labelled ACTUAL and ALERT
  lanes without replacing CARIO baseline fields;
- Vietnamese text is encoded in valid UTF-8 XML parts;
- workbook generation does not require Microsoft Excel or Office COM;
- simple readable header formatting is permitted but not required to change the
  meaning of a cell.
- the default application workbook export selects the official source snapshot
  when available; a non-authoritative preview requires the explicit preview
  export route.
- a user who wants to inspect an exported workbook MUST use the explicit
  `XLSX Preview` source-intake action and a fresh compiler-generated workbook;
  successful upload is visibly labelled `Read-only` and `Non-authoritative`.
